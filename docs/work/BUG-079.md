**Logged:** 2026-10-01 · **Source:** BUG-077 commit-door run (README § Cloud sessions added a fenced `#!/bin/bash`)

Effect: phantom anchors widen the reverse-citer lookup, and a link to a non-existent heading is never reported broken.
