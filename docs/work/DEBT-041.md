# DEBT-041 — docs/techstack.md § Edit Discipline is a parallel-authored fork of edit-discipline.md lore, already diverging

**Logged:** 2026-08-01 · **Source:** cold `audit-harness-edits` probe, finding #1, surfaced while auditing an unrelated CLAUDE.md edit
**Problem:** `docs/techstack.md` § Edit Discipline (line 38 onward) is a near-verbatim re-author of `.claude/guidelines/work-discipline/edit-discipline.md`. Both carry the same preference order (LSP rename → per-occurrence Edit → sed → replace_all), the same pre-flight checklist, the same banned-terms list, and the same recovery protocol. The lore file additionally carries a § Stale-state edits section that `techstack.md` lacks entirely — the two bodies are already out of sync. This violates `axiom-principles/harness-md-discipline.md` § Pre-flight ("If a related upstream rule exists, extend / addenda / refer — never re-author in parallel"); any banned-terms update must now be made in two places.

Constraint: the obvious fix — reduce `docs/techstack.md` § Edit Discipline to a redirect stub pointing at the lore file — breaks downstream self-containment. `plugins/super-bootstrap/skills/harness-bootstrap/assets/techstack-skeleton.md` (line 37) seeds a § Edit Discipline section into every bootstrapped repo; `claude-md-skeleton.md` (line 94) points at `docs/techstack.md#edit-discipline`. Bootstrapped repos have no `.claude/guidelines/` tree unless they separately run the claude-config-manager pipeline, so a redirect to lore would dangle downstream — exactly what `.claude/rules/repo-boundary.md` § Taste-coupling forbids for shipped skeletons. Fix must keep `docs/techstack.md` (and the skeleton it seeds) self-contained for downstream consumers while eliminating the parallel fork.

Interim applied (this session): CLAUDE.md § Edit Discipline split its two pointers by scope — `docs/techstack.md` § Edit Discipline owns banned-terms / checklist / recovery; `edit-discipline.md` owns the § Stale-state edits half. Removes the dual-authority ambiguity in the ambient layer but does not deduplicate the two bodies.
**Area:** `docs/techstack.md` § Edit Discipline; `.claude/guidelines/work-discipline/edit-discipline.md`; `plugins/super-bootstrap/skills/harness-bootstrap/assets/techstack-skeleton.md` (line 37); `plugins/super-bootstrap/skills/harness-bootstrap/assets/claude-md-skeleton.md` (line 94)
**Prior:** Make `docs/techstack.md` the single maintained source for the banned-terms / checklist / recovery body; rewrite the lore file to refer rather than re-author (adding the § Stale-state edits section to `techstack.md` to close the current gap). The skeleton and downstream consumers stay self-contained; the lore file becomes a thin addendum.
