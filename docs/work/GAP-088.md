# GAP-088 — Rename the entry skill: `/super-bootstrap:super-bootstrap` is awkward to type

**Logged:** 2026-09-23 · **Source:** GitHub issue #75 (via `/pull-issue`)
**Problem:** The entry is advertised as bare `/super-bootstrap`, but in the slash menu / skill listing it surfaces as `/super-bootstrap:super-bootstrap` (plugin name == skill name) — long, repetitive to type, and easy to mistake for one of the namespaced sub-skills. Proposal: rename to a short verb (e.g. `/super-bootstrap:init` or `:setup`) alongside the other namespaced doors (`:todo`, `:log`, `:commit`); keep the old name as an alias for one or two releases; add a `rename-map.md` row so pipeline-owned files naming the old entry migrate on re-sync. Verify: the new name launches the entry; the old form still works during the deprecation window; the rename-map sweep flags old literals in a synced repo.
**Area:** `plugins/super-bootstrap/skills/super-bootstrap/`, `plugins/super-bootstrap/skills/harness-bootstrap/assets/rename-map.md`, README / docs naming the entry
**Prior:** Whether Claude Code's plugin loader supports a skill alias (vs. a duplicate stub skill dir) is unverified.
