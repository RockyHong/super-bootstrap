# BUG-046 — commit §3b premise-closure enumeration structurally cannot reach registry/index docs, including the scaffolded `decisions.md`

**Logged:** 2026-08-26 · **Source:** GitHub issue [#51](https://github.com/RockyHong/super-bootstrap/issues/51) — maintainer, measured in a private downstream runway repo (identifiers scrubbed; keep them out); both cited lines verified unchanged at `main` v2.39.0
**Problem:** §3b of [`/super-bootstrap:commit`](../../plugins/super-bootstrap/skills/commit/SKILL.md) (premise-closure lane) enumerates which docs a product-anchor revision reaches as `doc-links.sh refs <anchor>` ∪ the glob `docs/work/GAP-*.md` + `docs/specs/*.md`. The reverse index is a by-product of the `ssot-doc-link` / `doc-link-discipline` link-candidate predicate, which deliberately excludes guard 3 (catalog / index / registry) and guard 4 (ephemeral) docs; the glob restores only the guard-4 class. So the guard-3 class has no covering lane by construction, and adding links cannot fix it — the linking discipline says those docs must not be linked. Two predicates with different jobs (link-worthiness for reader navigation vs closure-membership for blast radius) are used as one ruler. Not a repo-shape edge case: `harness-bootstrap` scaffolds `docs/decisions.md` into every repo as a `## Closed Forks` table — a registry — so §3b can never enumerate it anywhere, and a premise revision is exactly the moment its "rejected X because premise Y" rows should be re-examined; scale-module repos lose `docs/parked.md` the same way. Second layer: §3's routing line sends the anchor portion through §3b *instead of* the behavior scan, so an anchor-only diff leaves "the rest of the diff" empty and the basename-grep lane never fires — §3b has no second net. Measurement (one repo): 18 non-anchor `docs/**` files excluding `docs/work/`; `refs` returns 7; all 18 contain the anchor's basename literally; 5 are guard-3-excluded and permanently unreachable (three `index.md`, one ledger table, `decisions.md`); `docs/specs/` empty there, so half the glob is a no-op. Latent — the anchor block was never revised across ~86 commits, so no natural regression signal; verification must be constructed. A past-tense chronicle doc is correctly absent (cannot be staled by a premise revision) — a fix must not sweep it in. Note the [closed fork](../decisions.md#closed-forks) rejecting a pure reverse-link gate for §3 stage 1 ("the link graph errs false-negative … only behind a hybrid trigger"): §3b adopted the rejected shape with only a glob as backstop, so this card is that fork's reasoning applied to §3b, not a re-walk of it.
**Area:** `plugins/super-bootstrap/skills/commit/SKILL.md` §3 routing line (`instead of`) + §3b enumeration (the `docs/specs/*.md` literal appears nowhere else in the plugin) · `plugins/super-bootstrap/skills/commit/assets/doc-links.sh` · `plugins/super-bootstrap/skills/harness-bootstrap/SKILL.md` (`decisions.md` scaffold)
**Prior:** (a) default — invert the enumeration to `docs/**/*.md` minus the consumable set (non-GAP cards under `docs/work/`); cost acceptable since the premise lane fires rarely; transparent to consumers. (b) escape hatch — a project-declared closure map read the way `/todo` and `/drain` read `venue-map.md`; needs a per-repo migration before it takes effect. (c) "each repo adds links" — cannot close guard 3 by definition. (a) and (b) compose. Whichever lands, replace the `docs/specs/*.md` literal, and state the adopted proposal when closing #51 — it decides whether consumer repos have follow-up work. Verify: `doc-links.sh refs docs/overview.md` diffed against `docs/**/*.md` minus `docs/work/` shows `decisions.md` absent before, present after.
**Test-feel:** doc-only
**Blast:** pkg

## Verdict — surface · 2026-08-26

### Findings

- **root cause (both layers verified, this repo, plugin source at `main`):**
  - **Layer 1 — enumeration.** `bash plugins/super-bootstrap/skills/commit/assets/doc-links.sh refs docs/overview.md` returns exactly 5 paths: `README.md`, `docs/agents/domain.md`, `docs/agents/triage-labels.md`, `docs/specs/harness-architecture.md`, `docs/techstack.md`. The §3b union adds `docs/specs/*.md` (2 files, one already in `refs`) + `docs/work/GAP-*.md` (1 file). `docs/**/*.md` minus `docs/work/` minus the anchor = 10 files. **5 are structurally unreachable: `docs/decisions.md`, `docs/parked.md`, `docs/test-queue.md`, `docs/outward.md`, `docs/agents/issue-tracker.md`** — the registry/index class, exactly the card's guard-3 set. `decisions.md` is scaffolded into every runway repo unconditionally (`skills/harness-bootstrap/SKILL.md:186`, asset row `:303`), so the hole is repo-shape-independent.
  - **Refinement to the card's mechanism claim (does not falsify it).** Guard 3 is not a file-level link ban — `docs/decisions.md` carries 12 outbound markdown links and `docs/agents/issue-tracker.md` carries 5. What is true is narrower and still fatal: the predicate *never requires* a registry to link the anchor, so the reverse index cannot be relied on to contain one, and no rule in `doc-link-discipline.md` would put it there. Empirically `decisions.md` mentions the anchor twice (`:11`, `:65`) and both are non-link (a code span and a plain doc-name), so `refs` misses it. Card's "adding links cannot fix it" holds as "the discipline offers no lever that forces it"; the stronger reading ("those docs must not be linked") overstates guard 3.
  - **Layer 2 — no second net, and the loss is measurable.** `skills/commit/SKILL.md:20` reads `route the anchor portion through §3b **instead of** the behavior scan; the rest of the diff continues through this gate`. An anchor-only diff leaves "the rest" empty, so the basename-grep lane never runs. That lane is the one that *would* have reached the registry: term extraction yields `overview` (not on the generics drop-list), and `grep -c -i overview docs/decisions.md` = **2**. So `instead of` removes the single lane with coverage over the guard-3 class. The §3 citer lane is no backstop — it runs the same `doc-links.sh refs <path>`, returning the same 5.
  - **Second-order limit on the obvious layer-2 patch.** Routing the anchor through *both* lanes puts `decisions.md` in front of `doc-sync-scan`, whose rubric is behavior staleness, not premise framing. It is a coverage net, not the right judge — layer 2 alone does not close layer 1.
- **aim:** live. No open card overlaps (`BUG-045` touches the same `assets/doc-links.sh` but is a `check`-mode runtime cost bug, disjoint concern; `DEBT-080..083` / `GAP-064` are harness-bootstrap and venue-map lanes). Not a re-walk of `docs/decisions.md:36` (the rejected pure-reverse-link swap for §3 stage 1) — that row's ratio decidendi is *the link graph errs false-negative, evolution only behind a hybrid trigger*; §3b shipped the rejected pure-link shape with a glob as its only hybrid partner, so this card **applies** the fork's holding to a surface it did not cover. A fix that broadens §3b's enumeration moves with the row, not against it. No amendment needed there.
- **scope reach:** `plugins/super-bootstrap/skills/commit/SKILL.md:20` (routing `instead of`) + `:29` (the enumeration union — the `docs/specs/*.md` literal appears nowhere else in `plugins/`, confirmed by grep). Closure-carrying consumer: `plugins/super-bootstrap/agents/premise-closure.md:13` restates the set verbatim as "GAP cards, specs, and any doc the reverse-link index names", and `:17` names per-doc reading procedure by that same taxonomy ("a GAP card's origin block, a spec's premise paragraphs") — any enumeration change makes both lines stale in the same commit. Read-and-confirmed-unchanged under every candidate option: `plugins/super-bootstrap/README.md:17,:59`, `docs/overview.md:61`, `CLAUDE.md:71` and its shipped twin `skills/harness-bootstrap/assets/claude-md-skeleton.md:71` (all narrate the gate's existence, none restate the enumeration); `docs/specs/harness-architecture.md` does not narrate §3b at all.
- **provenance:** `plugins/super-bootstrap/**` is this repo's own source — edit here. `.claude/guidelines/work-discipline/doc-link-discipline.md` (the guard-3 predicate) is **served from the personal claude-config repo** (`CLAUDE.md` § Rules); it is out of this card's fix surface by the card's own framing, and were it ever in scope the route is `/contribute`, never a local edit.
- **attempted:** static read + the card's verify recipe run live; stopped at the gate-4 check (below) rather than sizing a fix.

### Decision needed

Gates 1–3 pass (mechanism named to the line; scope = 2 files in one plugin; the enumeration delta is shell-checkable). **Gate 4 fails** — the replacement enumeration predicate is a design call with consumer-visible consequences, and the card's own default option carries an unresolved internal conflict.

**The fork — what replaces "link-worthiness" as §3b's closure-membership ruler?** (Layer 2 — deleting `instead of` so the anchor also runs the behavior scan — is strictly additive, cheap, and compatible with every option below; treat it as a rider, not an alternative.)

- **A — invert to `docs/**/*.md` minus a consumable set** (card Prior (a)), keeping the `refs` union as redundancy and replacing the `docs/specs/*.md` literal. No consumer migration; transparent on upgrade. **Unresolved inside A:** as literally worded ("minus non-GAP cards under `docs/work/`") it sweeps in the past-tense chronicle doc the card says must stay out — so A ships only with an explicit exclusion clause, and that clause must admit `decisions.md` (a history doc the card wants judged) while excluding a chronicle. The discriminator has to be written, not assumed. Cost: in a 49-doc downstream repo (see `BUG-045`) A hands a Sonnet judge ~40 docs per anchor revision; the card's "fires rarely, cost acceptable" is the author's lean, not a measurement.
- **B — project-declared closure map** (card Prior (b)), read the way `/todo` and `/drain` read `venue-map.md`. Precise per repo, no sweep cost; needs a per-repo migration before it takes effect, which means every existing consumer runs uncovered until they adopt it, and closing issue #51 has to say so.
- **C — A now, B as a later escape hatch behind a named trigger** (they compose per the card).

**recommendation: C, with the layer-2 rider** — land A plus the exclusion clause and drop `instead of` in the same commit (closes the hole for every consumer with zero migration and restores a second net), and park B in `docs/parked.md` behind a doc-count trigger so the sweep cost is addressed when a repo actually feels it. This is also the shape `docs/decisions.md:36` sanctions: a hybrid trigger, not another single-predicate gate.

**Also for the user:** (i) the exclusion clause's wording is the one piece needing a human call — name it before dispatch; (ii) `agents/premise-closure.md:13,:17` must ride the same commit; (iii) issue #51's close note must state the adopted option, since it decides whether consumer repos have follow-up work.

## Design — 2026-08-26

Ruling on the surface verdict (autonomous run under the user-confirmed anchor): **option A, no exclusion clause; B closed, not parked; layer-2 by construction.**

- **Enumeration** — new `doc-links.sh closure <anchor>` subcommand prints the doc surface CLAUDE.md § Doc Sync defines (`docs/**/*.md` + root `README.md` + `plugins/*/README.md`) minus consumables (`docs/work/{BUG,DEBT}-*.md`, `docs/work/TEMPLATE.md`) minus the anchor itself. §3b enumerates by calling it; the `refs` union and the `docs/specs/*.md` literal go. Mechanical, testable, zero consumer migration.
- **Chronicle docs stay in the set; the judge discharges them.** The verdict's gate-4 conflict (A sweeps in a past-tense chronicle the card says must not be re-framed) is resolved at the judgment layer, not the enumeration layer: `agents/premise-closure.md` step 2 names the reading for a registry row (its Because / premise column) and for a past-tense chronicle (premise-independent → `holds`). Writing a filename/marker discriminator into the enumerator would be option B's config in disguise. Cost = one extra cold read per anchor revision, a rare event.
- **Layer 2** — with the closure set = the whole surface, §3b is itself the widest net; §3's routing line is reworded to state that (the anchor portion's closure is the full surface, so no behavior-scan backstop is owed), not to route the anchor through the behavior judge whose rubric is staleness, not framing.
- **B (project-declared closure map)** → `docs/decisions.md` § Closed Forks with a measured-cost reopen condition; it would otherwise be re-proposed (the issue already does).
- **Closure riders** — `agents/premise-closure.md:13,:17` ride the same commit; issue #51 gets a comment naming A as adopted (transparent to consumers on plugin update).
