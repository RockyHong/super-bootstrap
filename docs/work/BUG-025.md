# BUG-025 — render-menu.py frontmatter parser leaves YAML single-quote escapes doubled (`card''s`)

**Logged:** 2026-08-05 · **Source:** live `/super-bootstrap:help` invoke during BUG-023 fix verification, 2026-08-05 — the `/super-bootstrap:triage` row rendered `every card''s pickup`
**Problem:** `render-menu.py`'s hand-rolled frontmatter reader strips a value's outer quotes but never unescapes YAML's doubled-apostrophe form, so a single-quoted `description:` carrying an escaped apostrophe emits it doubled. Nine bundled `SKILL.md` / agent files use single-quoted descriptions. The corrupted string is what the gateway re-renders the menu from, so it reaches the user rather than stopping at raw tool output.
**Area:** `plugins/super-bootstrap/skills/help/assets/render-menu.py:45` (`.strip().strip('"')`), `:62` (`.strip("'\"")`)
**Prior:** Suspect the fix is an unescape step keyed to which quote style was actually stripped — `''` → `'` for single-quoted values only, since a doubled apostrophe inside a double-quoted or bare value is literal. A general YAML parser is not available (stdlib has none) and would exceed the script's zero-dependency shape.
