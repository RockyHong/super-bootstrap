# DEBT-063 — the doc-sync scan's cost per commit is out of proportion to what it returns

**Logged:** 2026-08-10 · **Source:** the operator, after watching five commits land in one session
**Problem:** Every commit whose diff touches a narrated path dispatches a cold agent that re-reads the doc surface from scratch. Measured across this session's five commits: 33.7k + 38.4k + 30.9k + 46.8k + 28.4k = **178.2k subagent tokens, averaging ~35.7k per commit**. One of the five returned an actionable candidate (a one-clause edit to `docs/agents/domain.md`); the other four returned `clean`. The mechanical grep-gate that exists to avoid the dispatch fired on **5 of 5** — terms like `decisions`, `harness-architecture` and `help` hit the doc surface trivially, so the pre-filter filtered nothing. The cost also lands on the smallest commits: the run that scanned a two-file, 26-line diff (a decisions row plus a card amendment) still spent 28.4k. Whether this is the cheapest shape that buys the guarantee, or a cold full re-read where a scoped one would do, has never been asked — the door was designed for correctness and its cost was never measured against alternatives.
**Area:** `plugins/super-bootstrap/skills/commit/SKILL.md` §3 grep-gate + §4 dispatch; `plugins/super-bootstrap/agents/doc-sync-scan.md` (what the cold agent is asked to re-derive each run); the doc-surface enumeration both share
**Prior:** Two candidate cost drivers, both unverified. First, the gate's term extraction is path-structure only and its drop-list holds seven generics, so any diff touching a doc-shaped path dispatches — a gate that never says no is a cost, not a filter. Second, the agent re-reads the whole surface cold on every run with no reuse of the link index `assets/doc-links.sh` already builds, and the reverse-link lookup that would scope it is closed in [`docs/decisions.md`](../decisions.md) on error-direction grounds (link graph errs false-negative) — that row bounds the fix but was argued on coverage, never against a measured cost. Adjacent: `DEBT-062` measures the same scan's judgment as unreliable on the hard case, so this is cost-per-commit weighed against a return that is itself partial. Any re-shaping is model-obeyed prose behind `.claude/rules/skill-authoring.md`'s RED gate, and the guarantee it currently buys — no superseded prose ships silently — is the thing a cheaper shape has to keep.
