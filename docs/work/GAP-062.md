# GAP-062 — thread-state ladder has no shape for a ruled-but-externally-blocked card

**Logged:** 2026-08-20 · **Source:** GitHub issue [#46](https://github.com/RockyHong/super-bootstrap/issues/46) (RockyHong) — observed on two cards in a downstream repo right after aligning its thread contract to 2.35.1 (`render-board.py`, full mode)
**Problem:** A user's ruling on a `## Verdict — surface` lands as a `## Design` block. When the ruling is "keep this card open and wait on an external party" (a signing reply, a second machine, a third-party account), the card carries Verdict → one-line approved Design → no Plan, so the ladder emits `Start execute: … | aimed | blocker none` and the row counts toward Cloud. Nothing on the card is executable — the settled aim is to wait — yet a drain wave admits the row (Cloud, not hard-blocked) and spins on it, and the need-me board hides it behind the drainable count, so the user never sees that a wait is outstanding. Reproduce: origin + `## Verdict — surface` + `## Design` whose body says the aim is to wait on an external reply + approval line, no Plan → expected: not a `Start execute` row, not counted in Cloud — held as `pending unblock` or absent per the chosen route; current: `Start execute … | aimed | blocker none`, Cloud +1.
**Area:** `plugins/super-bootstrap/shared/classify-actionable.md` (ladder + coupling gate), `plugins/super-bootstrap/skills/todo/assets/render-board.py`, `bench/todo-board/` (needs a fixture card for the shape); ruling surfaces: `plugins/super-bootstrap/skills/triage/SKILL.md` surface-absorb step, `docs/work/README.md` thread contract Design line
**Prior:** Two candidate routes, undecided — (a) a mechanical blocked marker the Design block can carry (e.g. `**Blocked on:** {external party}`) that the coupling gate treats like a hard blocker → row held out of the body, counted in `pending unblock`; (b) a ruling whose aim is "wait" routes to `docs/parked.md` (trigger-named entry) and the card resolves, with the contract saying so where rulings are written. Either way spec + script move together.
