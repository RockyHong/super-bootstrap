# BUG-055 — doc-links.sh slug drops only an enumerated punctuation list; GitHub-valid anchors report broken

**Logged:** 2026-08-28 · **Source:** GitHub issues [#57](https://github.com/RockyHong/super-bootstrap/issues/57) / [#58](https://github.com/RockyHong/super-bootstrap/issues/58) / [#59](https://github.com/RockyHong/super-bootstrap/issues/59) / [#60](https://github.com/RockyHong/super-bootstrap/issues/60), pulled via `/pull-issue` — one defect, four reports
**Problem:** `SLUG_AWK` strips punctuation by literal enumeration — ASCII at line 146, a unicode alternation (`—|–|…|：|，|。|、|（|）|「|」|『|』|【|】|！|？|；|·|“|”|‘|’`) at line 147. Any mark outside those lists survives into the computed slug where `github-slugger` drops it, so `check` reports `anchor not found in target` for links that resolve on GitHub. Confirmed missing from the reports' repros: `×` (U+00D7), `§` (U+00A7), `°` (U+00B0); #59's census of one consumer repo's heading surface adds `·` (U+00B7), `→` (U+2192), `（` `）` (U+FF08/FF09), `，` (U+FF0C), `：` (U+FF1A) — 9 standing false positives on every commit there. The failure is false-positive, not false-negative, but [the commit door's link-integrity layer](../../CLAUDE.md#doc-sync-non-negotiable) runs on every non-deferred commit and demands "fix or acknowledge, never silently skip" — a permanent block of unfixable red trains the operator to wave the whole gate through.
**Area:** `plugins/super-bootstrap/skills/commit/assets/doc-links.sh` lines 146–147 (`SLUG_AWK`, shared by `anchors` / `refs` / `check` — one edit covers every reader)
**Test-feel:** unit
**Blast:** pkg
**Prior:** #59's claim (the fullest of the four): per-character extension cannot converge — match `github-slugger` by dropping Unicode punctuation/symbol categories (`P*`, `S*`) while keeping letters/marks/numbers. Counter-constraint it names: CJK ideographs are category `Lo` and `github-slugger` **keeps** them, so a blanket "strip non-ASCII" breaks Chinese-heading anchors in the opposite direction. Fallback if portable awk can't do Unicode categories — extend the enumeration with the characters above and record in the `SLUG_AWK` comment that the list is ASCII-only by construction. Verify: `anchors` on a `§`-prefixed heading emits the slug without `§`; a CJK heading still emits its characters; `check` passes links already written in GitHub's own anchor form.
