# GAP-049 — doc-sync gate has no wikilink detection — missing links uninserted, broken links unchecked

**Logged:** 2026-08-02 · **Source:** user capture via /super-bootstrap:log
**Problem:** The doc-sync gate (commit door grep-gate + `doc-sync-scan` agent) has no wikilink awareness. Two sub-problems ride the same gap: (1) docs that were authored without following the `ssot-doc-link.md` born-linked discipline (concepts used substantively with no link to their SSOT home) pass doc-sync undetected — missing links are never inserted retroactively by the pipeline; (2) existing markdown links are never validated against their targets — a renamed file, a moved section, or a wrong anchor silently survives every commit. The adjacent `ssot-doc-link.md` rule fires at authoring time (on doc reads) but has no pipeline-level enforcement or repair pass, so the born-linked discipline is aspirational for already-committed docs and unverified for new ones beyond the authoring moment.
**Area:** `plugins/super-bootstrap/agents/doc-sync-scan.md` (scan predicate); `plugins/super-bootstrap/skills/commit/SKILL.md` §3 (grep-gate); `.claude/rules/ssot-doc-link.md` (adjacent authoring-time discipline)
**Prior:** Evaluate separately: (1) missing-link insertion — requires semantic detection of substantive concept uses against a known-SSOT map, likely a scan-agent addition or a dedicated lint pass; (2) broken-link validation — a mechanical check (target path/anchor exists) that could sit in the grep-gate pre-filter or as a cheap pre-scan step. Decide whether both sub-problems share one mechanism or warrant separate gates.

## Design — 2026-08-02 · settled with user (trio batch) — re-cut: build the doc reference graph

Reframe (user's): prose, unlike code, has no compiler-enforced entry points — links are the manufactured ones. Links are the doc graph's edge set; doc-sync is then a reachability query (diff touches X → who references X = closure candidates). The current grep-gate is this graph's degenerate form (basename mentions as pseudo-links); the upgrade is formalization, not replacement.

- **(a) Graph integrity — broken-link check.** Mechanical script (target path + anchor existence) as a commit-door pre-filter step; zero model tokens; findings listed to the gateway alongside the stage. Same mechanization class as the DEBT-045 help finding.
- **(b) Graph coverage — missing-link backfill is capital investment, not cleanup.** Incremental: any doc a session substantively edits gets its born-linked check (the `ssot-doc-link` rule already fires there); bulk backfill rides `/check-docs-consistency`. Never a per-commit semantic scan.
- **(c) Reverse index.** Derive target→referrers mechanically (scan all doc links once, invert; regenerable cache). Consumers: DEBT-023's structural gate stage-1, GAP-046's closure enumerator.
- **Error-direction contract.** Link-graph errs false-NEGATIVE (unlinked docs invisible) where grep errs false-positive — so hybrid trigger (grep-hit OR link-hit) until coverage is measured trustworthy; switching to pure link-gate on unmeasured coverage is forbidden.
- **Transport-gradient principle (user's).** Layer the pipeline monotonically: script → (cheap-model tier only where a measured volume leaks past the layer above) → Sonnet scan → gateway+user repair at the terminal. Layers are added on measured leak volume, never pre-built — today's data shows stage-1 precision, not a missing middle tier, is the bottleneck.
