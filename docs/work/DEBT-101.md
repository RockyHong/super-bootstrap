**Logged:** 2026-08-27 · **Source:** gate replay on this repo's last six commits + consumer field measurement (one lane-3 bug-fix commit, super-bootstrap v2.41.1)
**Problem:** Four mechanical noise sources in `/super-bootstrap:commit` §3 make the "diff narrates nothing" exit practically unreachable and inflate the dispatched scope when it is reachable. (4) Scope size is never reported — a hub doc (13 citers) fans out silently, no ceiling.
