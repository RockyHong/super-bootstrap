# GAP-081 — the doc-sync gate has no mechanical lane for restated machine-readable tokens

**Logged:** 2026-09-13 · **Source:** `GAP-080` close-out (`git log --grep=GAP-080`) — three cold probes over the doc surface, the commit door's lanes, and the repo's drift history
**Problem:** Nine confirmed doc-drift misses over 4.4 months share one shape: the stale text restates a token that exists verbatim in a machine-readable place — a frontmatter `model:` value, a directory count, a manifest field, a frontmatter `paths:` glob list. The gate has no lane that reads a source file's *body*. [`doc-links.sh`](../../plugins/super-bootstrap/skills/commit/assets/doc-links.sh)'s `check` mode resolves every link but verifies path and heading **existence** only; the four enumeration lanes (`terms`→`hits`, `anchors`→`refs`, `self`, link-target extraction) compute *which docs to read*, never *whether a claim still holds*. Claim-vs-source comparison exists in exactly one place — the judgment step ([`doc-sync-scan.md`](../../plugins/super-bootstrap/agents/doc-sync-scan.md) § Scan step 4, "Linked line") — so every restated token rides on a model noticing it. Both ways that can fail have shipped: a judge clearing an in-scope stale line (`9454187`, found 2 days later) and a doc never entering scope at all (`2c4c21f`, found 29 days later).
**Area:** [`doc-links.sh`](../../plugins/super-bootstrap/skills/commit/assets/doc-links.sh) (new mode, sibling of `check`); [`skills/commit/SKILL.md`](../../plugins/super-bootstrap/skills/commit/SKILL.md) §3; the doc surface [`CLAUDE.md` § Doc Sync](../../CLAUDE.md#doc-sync-non-negotiable) defines
**Blast:** repo · **Test-feel:** unit
**Prior:** A whole-surface mechanical lane over a closed vocabulary — see the Design block; it is settled, not proposed.

## Design — 2026-09-13

Settled at route time on the probe read-out; the user ruled the re-aim (`GAP-080` measured the judge, this mechanizes past it).

**Key on code-shaped path mention, never on the markdown link.** All 15 model-tier claims on the doc surface carry **zero** links to the agent file whose frontmatter they restate — a link-keyed lane scores 0% on the exact class that already broke. Link compliance splits by sentence shape, not fact kind: index-style bullets link at 60–70%, while table cells and `A → B → C` flow-arrow sentences almost never do, and the machine-readable facts concentrate in the latter. The `hits` lane's existing matchers (`wordin` / `pathin`) already recognize the backticked-path shape and already reached the `9454187` line — the pointer is mechanically present today, the follow-through is not.

**Whole-surface, not scope-scoped.** Attach as a sibling of `check` (`do_check`'s per-link walk, and its `case "$MODE"` dispatch), which already traverses the whole doc surface on every non-deferred commit. A lane that consults no scope sidesteps both shipped failure modes at once: it needs neither the judge to have looked nor the enumeration to have reached the doc.

**Closed vocabulary only — two checks in scope:**

1. **Model tier.** A line mentioning an `agents/*.md` path in code shape *and* containing one of `opus | sonnet | haiku | fable | inherit` → read that file's frontmatter `model:`; mismatch is a finding. Covers 15 lines across [`docs/overview.md`](../overview.md), the root [`README.md`](../../README.md) and [`plugins/super-bootstrap/README.md`](../../plugins/super-bootstrap/README.md).
2. **Roster count.** "N bundled skills" / "N dispatched subagents" / "N measured fixtures" → count the directory; mismatch is a finding. Two of the nine historical misses were this.

**Explicitly out of scope**, left with the judge: prose-level contradiction (the `todo` catalog row that claimed unconditional dispatch), behavioral invariants, and per-fact-kind comparators (glob-list equality, required-prerequisite presence). They need a rule each and none is closed-vocabulary.

**What this buys — latency, not coverage.** Expected reach is 2–3 of the 9 historical misses; the whole-surface backstop already catches ~8 of 9 *when it runs*. The gain is commit-time instead of 2–29 days, on the surface that ships to consumers. Sizing follows: this earns a small lane, not a framework. The cadence question the backstop raises is `GAP-082`, deliberately not this card.

**Dialect + verify.** Shipped skill asset → POSIX bash, portable-awk subset, fork-free inner loops ([`asset-dialects.md`](../../.claude/rules/asset-dialects.md)). RED first: a unit test planting one mismatched tier and one wrong count, asserting the mode reports both and stays silent on a clean tree.
