# GAP-058 — doc-sync guards the wrong boundary, and the format forks the truth it guards

**Logged:** 2026-08-11 · **Source:** the operator, after a measured tier sweep closed `DEBT-062` and `DEBT-063`'s aims together — successor to both
**Problem:** The aim the operator holds for doc-sync has never been specced: the doc surface is a web an agent penetrates quickly — breadcrumbs that expand, blast-area context reachable in a few hops — and the mechanism exists so a *future retrieval* never lands on two docs answering one question differently. The served party is the agent reading context, not the commit. What ships answers a different question. [`CLAUDE.md`](../../CLAUDE.md) § Doc Sync states a shipping guarantee at the commit door ("no superseded prose ships silently"), so the mechanism runs at write time, where it cannot know what will later be read — and therefore re-derives the whole doc surface on every commit. It does not deliver the retrieval guarantee either: five `clean` returns landed in one session while a live contradiction sat untouched in the surface the whole time.

Underneath the placement sits a format problem that no detector change reaches. SSOT wants one home per fact; separation of concerns splits docs by concern; a fact bearing on several concerns leaves the author two moves — link to the home (keeps SSOT, costs the reader a jump, slowing the very retrieval the mechanism protects) or restate it (fast retrieval, forks the truth). Restatement is what SoC plus readability demand, not author sloppiness. Detector work is therefore proportional to how much truth is forked, so every fix aimed at the scanner leaves the slope untouched. Transclusion reaches only the verbatim class; the hard class is **re-expression** — one question answered in two concerns' own idioms (a spec answers architecturally, a runbook operationally), same fact, no textual overlap to diff. Compounding it, the scanner derives claim identity at runtime (["write each assertion as the question it answers"](../../plugins/super-bootstrap/agents/doc-sync-scan.md) — its § Scan step 4), cold, per commit, from the diff: the door's most expensive and least reliable step.

Measured 2026-08-11, nine arms on the `DEBT-058` replay fixture (worktree at `d3161f3`, prompt = that commit's diff + date, identical across arms; the shipped 2.32.0 scanner text inlined into a general-purpose container because the pinned agent rejects a call-site model override). Against a contradiction whose duplicate carried a **claim-granular** link to its home: Haiku 0/3, Sonnet 3/3, Opus 2/3. Against one restated with only a **doc-level** link to the section it contradicts: Haiku 0/3, Sonnet 0/3, Opus 3/3 — and 0/6 for Sonnet counting `DEBT-062`'s earlier round. Link granularity, not difficulty, predicts recall: the caught duplicate cited its home on the claim itself; the missed one cited the section in general and then asserted over it. Tier is not the lever — downgrading is strictly dominated (Haiku returned `clean` on both with no volume saving) and raising is rejected on price.

A fix has to change the slope, and it has two forks to settle in order. First, **where the guarantee lives** — the write boundary it occupies now, or the read boundary the aim names, which dissolves per-commit whole-surface scanning. Second, **whether a fact gets an identity independent of its wording**, declared once by the author, so that two answers to one question is a mechanical contradiction rather than a semantic judgment — at zero retrieval cost, since the text stays inline. Operator constraint: no more bandaids. The next pickup solves this whole or does not start.

**Area:** [`CLAUDE.md`](../../CLAUDE.md) § Doc Sync (the guarantee's wording and placement); `plugins/super-bootstrap/skills/commit/SKILL.md` §3 grep-gate + §4 dispatch; `plugins/super-bootstrap/agents/doc-sync-scan.md` § Scan step 4; `.claude/guidelines/work-discipline/doc-link-discipline.md` § Home selection edges; `skills/commit/assets/doc-links.sh`; and the shape of `docs/**` itself

**Prior:** Two supporting observations, both verified this session. `doc-link-discipline.md` § Home selection edges instructs authors *not* to link when the candidate home contradicts the using line — so the link discipline removes the breadcrumb at exactly the failure point the scan is worst at; inverting that edge (a contradiction is when the pointer is most load-bearing, recorded as a supersession) is the cheapest candidate for fork two. And the running install lags the repo (2.31.0 loaded against 2.32.0 released), so `DEBT-063`'s per-commit cost figures were measured against the pre-step-4 scanner text. Bounds already closed in [`docs/decisions.md`](../decisions.md), not to be re-walked: the scan's coverage-line contract is closed on measured zero separation, reopenable only against a judgment-aimed fix measured on the same fixture; a pure reverse-link gate is closed on error direction (a link graph errs false-negative), hybrid only after link coverage is measured. That second row bounds fork two — undeclared assertions stay invisible under any link-walk, so a declared-relation layer shrinks what the semantic scan must derive and never eliminates it.

## Design — read-boundary guarantee, link-carried identity · 2026-08-11

Settled with the operator. The adopt-vs-build gate on prior-art comparison (Graphiti / mempalace) closed same-day, build side: both serve a **derived memory store beside the docs** (mempalace: verbatim conversation recall over local embeddings; Graphiti: LLM-extracted temporal triplets in a graph DB), neither touches authored docs in place — adoption re-imports dual-truth drift (docs vs store) plus infra sb's zero-runtime posture excludes. Graphiti's write-side tokenomics (multi-call extraction / dedup / edge-resolution / invalidation per episode, ~500–2000 in + 200–800 out) is the pay-on-write shape this redesign escapes; Zep's own optimization direction — deterministic IR first, LLM only as fallback — independently validates the mechanization boundary below. One concept-level overlap: Graphiti's edge invalidation ("old facts are invalidated, not deleted") is the same semantic as the supersession link, which is its file-native equivalent at zero marginal token cost and zero infra. Graphify (Graphify-Labs) is the nearest neighbor — deterministic tree-sitter graph for code at zero LLM cost, mechanical query-time traversal — but its free lane is code-only: prose enters the graph only through a per-ingestion LLM semantic pass (derived identity + rebuild staleness — pay-on-write again, on exactly the doc class), it has no contradiction detection, and sb's corpus is 100% prose, so what it would charge for is the whole surface. Phase B's reverse-lookup delivers the traversal this aim actually needs at grep scale, from author-declared links — ground truth, no extraction variance.

**Fork one — the guarantee moves to the read boundary.** [`CLAUDE.md`](../../CLAUDE.md) § Doc Sync's shipping guarantee ("no superseded prose ships silently") rewrites as a retrieval guarantee: *any restated fact a reader lands on reaches its home in one hop*. Carried by structure, not by per-commit whole-surface semantic judgment. Ground: the nine-arm measurement — recall tracked link granularity, not tier, and the caught duplicate carried its home link on the claim line itself.

**Fork two — a fact's identity is the link on its asserting line.** The measured granularity difference sits in the *citing* line's placement, not the target anchor's depth: vanilla markdown link to the existing section anchor, placed on the asserting line rather than the paragraph head. No new syntax, no claim-ID registry, no anchor scheme; a registry stays an escalation path, entered only after same-fixture measurement shows section-grain reverse-lookup insufficient.

**Mechanization boundary — LLM judgment is paid once at authoring; everything downstream is mechanical.**

| Layer | Mechanism | Class |
|---|---|---|
| Catalog derivation | `find` + `awk` (sessionstart hook, as shipped) | mechanical |
| "Which docs bear on this prompt" | forced-eval YES/NO (as shipped) | LLM — measured floor; grep pre-filter and LLM-in-trigger-path are recorded failures |
| "Does this line restate a homed fact" | author declares by writing the link at edit time | LLM, paid once — `ssot-doc-link` rule already fires there |
| Link integrity | `doc-links.sh` check | mechanical |
| "This diff touched whose home → which citers to read" | reverse-lookup (grep citers of `file#section`) | mechanical |
| New-assertion residual | diff-scoped: "do these new lines answer an already-homed question" | LLM, diff-scoped — never zero, per the reverse-link-gate bound |

**Phases:**

- **A — authoring rules.** `ssot-doc-link` tightens to asserting-line placement, one link per claim-use. The contradiction edge inverts: a candidate home that contradicts the using line is where the link is *mandatory*, recorded as a supersession — `doc-link-discipline.md` § Home selection edges is CCM-served, so that inversion routes via `/contribute`; the sb-side rule text carries the same edge meanwhile.
- **B — mechanical tooling.** `doc-links.sh` gains a reverse-lookup verb (who cites `file#section`); the commit door adds link-integrity + reverse-citer read-set on touched homes. Additive — the grep-gate stays until D.
- **C — activation-layer absorption.** sb becomes SSOT of `consult-check-check.sh` + `consult-check-sessionstart.sh`, shipped by `harness-bootstrap` as the read boundary's activation layer; CCM's copy retires (operator: every repo runs sb, non-sb is by design out of scope); the bench assets move with the hook. The `docs/decisions.md` CCM-absorption row annotates reopened + answered when this ships.
- **D — commit-door shrink.** Whole-surface semantic scan → mechanical reverse-lookup + diff-scoped new-assertion residual. Gated by the reverse-link-gate bound: only after link coverage on this surface is measured trustworthy (hybrid trigger, never pure).
- **Measurement:** `d3161f3` fixture, identical protocol, before/after each phase that touches recall.

Bounds honored: the coverage-line row stays closed (this fix is structure-aimed, not judgment-aimed — no reopen); the reverse-link-gate row's hybrid condition is phase D's entry gate.
