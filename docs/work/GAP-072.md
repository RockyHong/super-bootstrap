## Amendment — 2026-09-09 · gateway session (collaboration probe)

Lighter route than a full per-runtime adapter: Claude orchestrates, Codex runs as a cold executor for build phases. Three live channels — `codex exec` via Bash (`-C <dir>`, `--sandbox`, `--full-auto`; stdout final message, `--json` for events), `codex mcp-server` (`codex` tool with `prompt` / `cwd` / `sandbox` / `approval-policy` / `base-instructions`, returns `threadId`; `codex-reply` continues; events go to `codex/event` notifications, not the response), and OpenAI's own `codex-plugin-cc` Claude Code plugin (`/codex:review`, `/codex:adversarial-review`, `/codex:rescue`, `/codex:transfer`, `--background` + `/codex:status` / `/codex:result`). Handshake cost is small (few-parameter schema, final message only); the real cost is Codex's cold re-read of the repo per spawn — so the dispatch unit must carry a propagation closure, same rule as § Dispatch. Under this route Codex needs only layer A plus a subset of layer B (a trimmed `AGENTS.md`: commit convention — report built + file list, never commit — coding standards, doc-sync held by the gateway), not the full adapter.

Gotchas that touch this repo's contracts: Codex sandbox is OS-level (`read-only` / `workspace-write` / `danger-full-access`) + approval policy, not an allow-list — drain's `worktree-settings.local.json` is inert for a Codex worker, isolation moves to `-C <worktree>` + `workspace-write`; Claude-side hooks see one Bash call, never Codex's internal writes, so the no-commit contract holds by prompt only; the return is a message, not a diff — gateway must `git diff` and re-Read touched files; MCP default timeout 60 s (`tool_timeout_sec` / `client_session_timeout_seconds`); no MCP passthrough either direction; `threadId` loss makes the thread unreachable; community `codex-as-mcp` bypasses sandbox by default. `/codex:transfer` ships the whole transcript and the review-gate loop drains quota (OpenAI's own warning).
