# GAP-068 — Outward items are flat rows in one file, so the author's queue is unreadable in a markdown reader and a reply has nowhere to land

**Logged:** 2026-08-28 · **Source:** pilot author reading `docs/outward.md` after the mover migration (10 entries in one file)
**Problem:** `docs/outward.md` holds every outward item as a `### OUT-###` chunk in one flat file. Two consequences. (1) **Unreadable where the author reads:** a markdown reader shows one long page; the work-card folder shows one file per item, which is the shape a human actually scans. (2) **No thread:** an outward item is a conversation by nature — a licence offer, a vendor reply, a portal review, a pitch round — and the flat row has no place for "they answered X on {date}, next move is now Y". Cards already carry the append-only thread contract (origin block + dated blocks, latest block leads, resolve = delete); the outward container re-invented a lesser shape beside it.
**Area:** `skills/harness-bootstrap/assets/scale/outward-skeleton.md` (+ `SKILL.md` §2a-scale plant / drift / adopt / registration lines, `assets/claude-md-skeleton.md` bracket line), `shared/classify-actionable.md` §c, `skills/todo/assets/render-board.py` + `bench/todo-board/`, `agents/todo.md`, `skills/log/SKILL.md`, `skills/commit/SKILL.md` exemption + `assets/doc-links.sh` frozen-provenance path + `bench/doc-links/`, `skills/check-docs-consistency/assets/tracker-annotation.md`, `skills/drain/assets/eligibility.md`, `skills/todo/SKILL.md` + `assets/scaffolds.md`, `scale/card-fact-fields.md`, plugin `README.md`; dogfood `docs/outward.md`, `docs/overview.md`, `docs/specs/harness-architecture.md`, root `CLAUDE.md` § Planning
**Prior:** One thread shape for every tracked item. The outward container becomes a folder — `docs/outward/OUT-###.md`, one file per item, the same thread contract as `docs/work/` — with `docs/outward/README.md` owning the admission bar + high-water and `TEMPLATE.md` the hand-copy path. The flat `docs/outward.md` retires; the sync splits an existing one mechanically.

**Test-feel:** unit (`bench/todo-board`, `bench/doc-links`, the split script on a fixture) · **Blast:** repo

## Design — 2026-08-28 · settled with user

1. **Folder, one file per thread.** `docs/outward/OUT-###.md`. Origin block frozen at capture: H1 `# OUT-### — {summary}`, then `**Logged:** {date} · **Source:** {where}`, `**Next move:**`, `**Waiting on:**`, `**Repo tail — fires on:**`, optional `**Owning card:**`. Appended blocks follow the work-card contract (`## Amendment — {date} · {source}` for a reply landed, a move done, a re-route; `## Progress — {date}` for durable state; end-of-file only, dated + sourced, never edited). **Latest block leads:** a block that restates `**Next move:**` / `**Waiting on:**` lines supersedes the origin's for every reader (board, log dedup, drain). Resolve = delete the file when the tail fires; git is the archive; citers de-link the same way cards do.
2. **`docs/outward/README.md`** owns what the flat header owned — admission bar (the next step is the author's hands or an outside party's **and** it names a repo tail), pointer-not-restatement, `OUT-###` ID convention + **ID high-water mark** line, the file shape, the two-group consumer note, the wall (`Owning card:`), and a one-line pointer to `docs/work/README.md` § Thread contract for the block vocabulary. `docs/outward/TEMPLATE.md` is the sanctioned hand-copy path, like `docs/work/TEMPLATE.md`.
3. **The flat file retires.** `harness-bootstrap` plants the folder on install; on sync, a consumer's existing `docs/outward.md` with entries is split mechanically by a shipped script (`assets/scale/split-outward.py <root> <readme-skeleton>`: high-water carried into the README, each `### OUT-###` chunk → `OUT-###.md` with the H1 + its field lines, the flat file deleted) — no per-item judgment, no consumer-side migration round. Registration lines (consumer `docs/README.md`, `CLAUDE.md` § Planning bracket line) point at `docs/outward/README.md`.
4. **Readers follow the folder.** `classify-actionable.md` §c reads `docs/outward/OUT-*.md` (origin fields, latest-block-leads); `render-board.py` encodes it; a lingering flat `docs/outward.md` still renders but earns a `# note:` naming the sync that splits it. `log` writes the file + bumps the README high-water. `commit`'s frozen-provenance exemption and `doc-links.sh`'s frozen path cover `docs/outward/OUT-*.md` (+ the README high-water bump), the tracker annotation names the folder, `drain` still never reads it.
5. `parked.md` / `test-queue.md` keep their shapes this round — neither is a conversation.

Approved — 2026-08-28 (user: "做成 thread 統一形狀才是好的").
