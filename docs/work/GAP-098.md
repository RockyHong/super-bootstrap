## Design — 2026-09-30

Settled with the user (gateway leans accepted): **seed first, work now, resolve on done.** Pipeline-produced pending work is carried by cards; the run does what it can in place, and an interruption leaves committed cards for cold pickup.

- **Two new fixed seed cards** in `setup/assets/seed-cards.md`, code-present only — *Seed feature specs* (resolve at pickup once `docs/overview.md` Module Index has grown; blocked on the overview card when one is open) and *Sweep code markers into cards* (TODO / FIXME / XXX / HACK markers + failing or skipped tests → candidates, cap ~5, user prunes, land through `/super-bootstrap:log`). Bodies carry the old Task 1 / Task 2 intent; preconditions ride the `Problem:` line and triage judges them at pickup.
- **Seed step in setup**, right after the runway returns and before the substantive check, both branches: code present (runway Phase 1 § Code presence) → seed each code-present card not yet seeded, commit through `/super-bootstrap:commit` (card-lifecycle). Seeded-once guard, mechanical: card present in `docs/work/` (H1 match) → skip; `git log -S"<H1 summary>" -- docs/work/` finds any commit → seeded before, skip; a `chore: complete pipeline bootstrap` commit exists → legacy bootstrap finished, skip.
- **Work now:** after the seed commit, setup picks up each seeded card whose precondition holds now by its ID — the ordinary pickup (framing + route + triage), no bootstrap-private path. Greenfield keeps stopping at its resolve gate after this step. Interrupted → the cards stay open; needs-me / triage / autorun see them.
- **Retire the plan substrate** in harness-bootstrap: `assets/bootstrap-plan.md`, the plan write, task adaptation, the missing-on-mature advisory, the plan's sync-report / receipt handling, the Phase 3 plan line, and the plan-related placeholder bullet.
- **Legacy migration** in harness-bootstrap § 2b: a leftover `.claude/bootstrap.md` (or legacy `docs/work/bootstrap.md`) → for each of Task 1 / Task 2 with an unchecked box, seed the matching card from `../setup/assets/seed-cards.md` (same guard), delete the plan, stage both; row `⊘ removed | updated`.
- **needs-me pointer** from `33e1dd3` removed — migration makes leftover plans visible as cards.
- **Cross-skill constraint** stated present-tense in `docs/specs/harness-architecture.md`: pipeline-produced pending work is carried by `docs/work/` cards, seeded before the work starts.
- Unchanged: `commit/assets/doc-links.sh` path exemption for `.claude/bootstrap.md` (legacy files may still sit in consumers until migration).
