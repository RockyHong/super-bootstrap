## Design — 2026-09-27

**Settled by:** user ruling on the Verdict's fork — option A (build the pressure-condition extension and measure, staged). Phase 0 ran gateway-inline before this block landed; its readings are the design's ground.

**Phase 0 readings (haiku, marker hooks, scratchpad fixture):** one `claude -p --input-format stream-json --output-format stream-json --verbose` process carries N user turns under one `session_id`; `SessionStart` fires once (`source=startup`) and never re-fires within the process; `UserPromptSubmit` fires once per turn. Hook stdout from either event reaches the model as `<event> hook success: <stdout>` context — a SessionStart line persists and appears exactly once on later turns; a UserPromptSubmit line lands fresh each turn and the earlier ones stay in the transcript. **Batch-feeding all user lines at once drops turns** (3 fed, 2 answered); the driver must wait for each turn's `result` event before writing the next user line. `-p` stream output carries no `type:user` echo, so turn boundaries are the driver's to mark.

**Arms (both use the shipped v2 sentence + compact catalog verbatim — the one variable is injection frequency):**
- (a) `forcedeval-v2` — as-is: UserPromptSubmit injects every turn.
- (b) `forcedeval-v2-once` — a SessionStart hook injects the identical block once at `startup`; no UserPromptSubmit hook. Chosen over a first-prompt-only stateful UPS hook because it is stateless, maps onto the shipped `consult-check-sessionstart` slot, and in production the `resume|clear|compact` re-fire is the refresh point a once-only design wants.

**Driver:** `run-multiturn.py` (Python — the bidirectional wait-for-`result` loop Phase 0 verified; bash `coproc` stays the declared degrade path). Per session: hermetic fixture reset (as `run-gap045.sh`), one process, turns fed sequentially from a script file, each turn prefixed in the raw output by a driver-written line `{"type":"bench_turn","turn":k,"id":"<probe-id>"}`. Env parity with `run-gap045.sh`: `MODEL`, `FIXTURE_DIR` (mandatory for scored runs), `REP`, `RUNS_DIR`, resumable by output-file presence.

**Scripts (`scripts-multiturn.jsonl`, one session per line):** turn 1 = a no-consult filler from the N set; turns 2–6 = five probes from `probes-gap045.jsonl` (4 consult + 1 no-consult), three scripts covering all 15 probes once, consult probes rotated so no probe sits at the same depth in two scripts. Recall is scored on turns ≥ 2 only — turn 1 is the injection turn and identical across arms.

**Scorer:** `score-multiturn.sh` — same doc-access rule as `score-gap045.sh` (Read or shell call naming a guidelines doc counts; keyed hit on `keyed_neighbor`), delimited per `bench_turn` marker; one TSV row per turn with `session, turn, id, set, arm, consulted, keyed_hit, input_tokens (fresh), rep`. Per-turn fresh `input_tokens` is the (a)-cost readout.

**Pre-registered gate:** pooled keyed recall on turns ≥ 2, Sonnet 5, 2 reps: switch the shipped hook to once-only iff (b) recall ≥ (a) recall − 1 miss per 18 consult cells AND (b) TN = (a) TN. Otherwise keep per-prompt and record the measured margin. Equal-at-6-turns is not a pass: a tie extends the scripts to 12 turns (second filler block) before the verdict lands. Expansion to Opus 5.5 + Fable 5.1 only if the Sonnet pilot passes the gate or lands within one miss of it.

**Product tail if (b) wins:** listed in the Verdict § scope reach — a separate cluster-7 harness change after the bench verdict, not this card's build.

## Amendment — 2026-09-27 · build return (Plan 1–5) + gateway verify

(4) `cost_usd` is the per-turn delta of the session-cumulative `total_cost_usd`.
