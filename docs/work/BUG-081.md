# BUG-081 — session-close never offers already-finished cards for resolve

**Logged:** 2026-10-02 · **Source:** field finding from consumer repo `D:/Git/Games/MusicExperiment` via `/send-note` (2026-10-01); skill text checked identical in 5.0.0 / 5.0.2 / 5.1.0
**Problem:** Cards stay open across sessions after their work is done, though `/super-bootstrap:session-close` ran at every close. The step-3 resolve rule ("**Cards this session finished** … whose work landed whole") matches only cards whose Plan the current session completed. Three shapes never match: (1) **superseded** — an Amendment moved the aim to a successor that was later resolved; the predecessor stays open, breaking `docs/work/README.md` § Aim switch ("resolve this card … and open a successor"); (2) **finished on another session/branch, then merged** — the merge move sweeps no cards the merge finished; (3) **finished in an earlier session** — every later close reports "no card finished this session", so the card is never offered again. Same consumer run, executor side: the gateway named the stale cards in its closing prose ("GAP-006、008、011、013、014 大多已完成或被取代，可以用 triage 收掉") but left them out of the confirm-pick, against the skill's own "Drive, don't narrate"; it executed the user's "收尾既有卡" as an amendment pointing at the successor instead of a delete; its close commit was raw `git commit`, not `/super-bootstrap:commit`.
**Area:** `plugins/super-bootstrap/skills/session-close/SKILL.md` step 3 (line ~43) and § Rules "Drive, don't narrate" (line ~77); `plugins/super-bootstrap/skills/needs-me/SKILL.md` ("look done or premise-dead" flag); `docs/work/README.md` § Aim switch
**Prior:** Sender's proposal — replace the bullet with a resolve-candidate sweep over every open card: candidate when (a) latest Plan/Progress reports every step done, (b) aim moved by Amendment/link to a card now absent or resolved in this close, (c) a branch merged this session carries commits naming its ID that cover its Plan, (d) the session's own text calls it done/superseded/closed; each → a resolve move with an evidence line, or a triage move when unsure; hard rule that a card judged done/superseded always enters the pick, never narrated only; optional mechanical pre-filter (cards linking a deleted card ID, card IDs in `git log` since last close); plus a one-line pointer from needs-me's flag to a resolve door. The raw-commit sub-point touches `docs/decisions.md` row "Widen the commit-channel hook" (its named lever: `/session-close` routing its commit move to the door).
