# BUG-071 — doc-links.sh lanes: self prints exempt card paths; anchors misses whole-file adds

**Logged:** 2026-09-23 · **Source:** GAP-087 measurement run — cold Opus greenfield bootstrap of an empty temp repo from the dev copy
**Problem:** `doc-links.sh self` prints `docs/work/README.md` / `TEMPLATE.md` on a scaffold commit although the commit door's frozen-provenance rules exempt `docs/work/` from the gate — the caller must pre-filter. For a new file whose H1 sits on line 1, `anchors <path> +1,N` returns the H1 slug instead of `(top)`, so `refs` runs at section grain on a whole-file add.
**Area:** `plugins/super-bootstrap/skills/commit/assets/doc-links.sh`, `tests/doc-links.test.sh`

## Verdict — surface · 2026-09-23

### Findings

- root cause (claim 2 — `anchors`): verified script gap. `do_anchors` (`doc-links.sh:782`) keeps only the range start (`start="${r%%,*}"`) and discards the length; `:787` `[ "$ln" -le "$start" ]` lets a heading sitting on the start line itself claim the range. A new file's `git diff -U0` hunk is `@@ -0,0 +1,N @@` → `+1,N` → start=1 → the line-1 H1 wins; `(top)` fires only when the start is strictly above the first heading. Repro on a 3-section fixture: `anchors docs/new.md +1,11` → `title`; same file with the H1 moved to line 4 → `(top)`. Consequence verified: `refs docs/new.md#title` prints nothing, while `refs docs/new.md` prints both a bare-link citer and a `#sec-a` citer — `do_refs:490-491` matches an anchored query on anchor equality, so a bare link never equals `title` — the citer read-set for a whole-file add is empty. Family: the same start-only read means a hunk spanning several sections yields only its first section's slug (`+1,11` on the fixture never emits `sec-b`); the whole-file add is the extreme instance. `(top)` has zero test coverage — `tests/doc-links.test.sh` exercises `anchors` only at `:253`, `:294`, `:299`, all mid-file headings.
- root cause (claim 1 — `self`): not a script defect. `self` printing `docs/work/README.md` / `TEMPLATE.md` is the script's stated contract — header `:65-66` "Each folder's standing files … are ordinary surface", `is_frozen_provenance_path` `:543-546` "Keyed on the ID pattern, not the folder" — locked by the bench golden `bench/doc-links/expected/self-mixed.txt` (README in, `BUG-001` out) and by `tests/doc-links.test.sh:860` for the sibling `pins` lane on the same predicate. The door agrees on the lane side: `commit/SKILL.md:23` (self bullet) lists the drop-outs as card threads / `OUT-###` / `dimension: history` — exactly the predicate — and `:19` says the standing README "stays in both lanes". The pre-filter the card names is the door's own instruction at `:19` — "Mixed diff → run the gate on the other paths only" — so it is caller-side by design. Residual: `:19` opens folder-keyed ("every changed path inside `docs/work/`") while its parenthetical enumerates lifecycle shapes (thread appends, deletions, README high-water bump); a scaffold's whole-file add of README/TEMPLATE is neither a thread nor a bump, so the door prose reads either way on that case. Code outranks prose: the script and the bullet's own parenthetical both say standing-file content changes gate. The scaffold-specific waste (judging verbatim skeleton text) is BUG-070's class — a scaffold commit tripping a door lane over placeholder text — one lane over.
- scope reach: claim 2 — `doc-links.sh` `do_anchors` `:775-794` + header `:50-55`; `tests/doc-links.test.sh` (new `(top)` lock); `commit/SKILL.md:22` reads unchanged (`(top)` ⇒ whole-file grain stays the contract). Claim 1 — no script change; at most a prose sharpening at `commit/SKILL.md:19` (behavior-shaping → `skill-authoring.md` RED floor).
- attempted: static read of both lanes + door §3; empirical runs — `self` on the real scaffold set (`docs/work/README.md`, `TEMPLATE.md` printed; `BUG-071.md` dropped), `anchors` / `refs` on fixtures (above); grep of tests + bench for locks; `docs/decisions.md` rows 38 (citer-lane inversion — per-hunk anchor narrowing is the measured win a fix must keep) and 54 (reverse-link hybrid) read, neither closes this; no `§ Probes` table in `docs/techstack.md` → no probes. Sibling cards: BUG-070 is the same scaffold-commit family, different lane; no duplicate. Stopped at verdict because the card bundles two claims with opposite grounding.
