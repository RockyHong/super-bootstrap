# GAP-087 — Greenfield runway: mechanize the empty-repo path into a bundled script

**Logged:** 2026-09-23 · **Source:** GitHub issue #74 (via `/pull-issue`)
**Problem:** On a truly empty repo (no files, no manifest, no source), `/super-bootstrap` still runs the full model-driven runway: the model reads the harness-bootstrap SKILL.md plus ~40KB of skeleton assets, renders CLAUDE.md's conditional blocks by hand (drops Coding Principles / monorepo / scale / example-rule blocks), hand-assembles the sync report with every row `⊕ new`, builds the runway receipt + `placed` hashes, routes the commit through `/super-bootstrap:commit` (doc-sync judgment over freshly-copied skeletons), and seeds the three fixed GAP cards through `/super-bootstrap:log`. Every step on this path is deterministic — no drift, no legacy content, no user-owned sections, and the opt-in gates (drain infra, scale module) resolve to skip on an empty repo. Many tokens and turns reproduce a fixed output, and hand-rendering the templates (ad-hoc regex over `{…}` blocks) is the step most likely to drift from the skeleton. Verify: `/super-bootstrap` in an empty dir yields an output tree + receipt byte-identical to the current model-driven run in one script call; a re-run afterwards takes the normal sync path and reports all `✓ current`.
**Area:** `plugins/super-bootstrap/skills/harness-bootstrap/` (Phase 1 detection, assets), `plugins/super-bootstrap/skills/super-bootstrap/`
**Prior:** Bundled script (e.g. `skills/harness-bootstrap/assets/scaffold-greenfield.py`) fired when Phase 1 detects empty/docs-only tree + no harness files + no receipt — copies verbatim assets, renders CLAUDE.md / techstack.md with docs-only + single-package + no-scale branches, writes `.claude/settings.json` (core pin + three hook snippets), copies hook scripts, appends `.gitignore`, writes the receipt (`version`, `covered`, `placed` sha256s) and cleanup-only `.claude/bootstrap.md`, seeds GAP-001..003 with the high-water bump, makes the two commits; the model path keeps everything with judgment (re-sync, legacy migration, code-present repos, forks).
