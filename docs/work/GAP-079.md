**1. Instance 1's layer — does the door gain a self-scope lane (the diff's own doc-surface files join the scan scope)?**

Enumeration-only: not prose intervention, not a `questions` coverage line, not grep→link-gate, not citer inversion — none of the four shapes the closed rows rule out.

- recommendation: **(a)** — smallest mechanical carrier, and it adds no procedure, only reach for one already written.
- settles by: no closed fork blocks it; the single open variable is cost — scope growth against the 8-doc inline ceiling.
