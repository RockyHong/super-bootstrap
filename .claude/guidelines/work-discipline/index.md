# Work Discipline — Tier 1 Subcategory

Universal principles for how Claude behaves at the work moment — tool-use safety, doc/info hygiene, AI-product integration patterns, cross-cutting craft rules.

Part of the `.claude/guidelines/` Tier 1 tree. The sibling subtrees — `axiom-principles/` (timeless principles) and `claude-shape/` (current factual snapshot) — are device-planted to `~/.claude/guidelines/`, not served into consumer projects.

This directory is storehouse-owned. `serve.sh` replaces it wholesale whenever source and consumer differ — a file added here is gone on the next sync, and the serve call names what it replaced. Route a wanted change to this lore through `/contribute`.

## Principles

| Principle | Summary | File |
|---|---|---|
| Trust upstream defaults | Default = upstream canonical wiring as shipped. Empirically prove canonical fails before authoring downstream overlay; date-stamp every overlay as decay debt. Applies to plugins, MCPs, SDKs, framework presets, library defaults. | [`trust-upstream-defaults.md`](trust-upstream-defaults.md) |
| Runtime parity | Place ambient-behavior config at the level where every target runtime loads it. Name runtimes, identify their loading layers, pick the lowest-common layer. Document parity exceptions explicitly when intentionally placing in a partial-coverage layer. | [`runtime-parity.md`](runtime-parity.md) |
| Model tiering | Unspecified `agent()` model inherits the main-loop tier; cost scales with fan-out width. Pre-launch tier audit (small retrieves / mid judges / top thinks, top tier = `inherit` — the session owner's model, and the cap no dispatch runs above), centrality amplifier (direction-setting steps tier to top regardless of own shape), width axis (tier pins cap unit price, fan-out constants cap volume), named-launch corollary (project copy via scriptPath, personal planted copy by name with the guard auditing it; stop-first when none), resume cache-key corollary. | [`model-tiering.md`](model-tiering.md) |
| Path portability | Context-loaded docs express filesystem locations portably — never hardcoded absolute machine paths (a clone/relocation mis-primes every reader). Relativize, don't re-absolutize. Canonical conventions block; setup-doc carve-out. Enforcement is grep-checkable — an absolute-path sweep over the context-loaded doc dirs should return the intentional env-setup hits and nothing in narrative prose. | [`path-portability.md`](path-portability.md) |
| Dispatch breadcrumb | Subagent dispatch prompt carries the scope's entry doc (path, not topic; entry point, not payload). Minimum unit of caller-supplied context; cheaper tiers under-read most. | [`dispatch-breadcrumb.md`](dispatch-breadcrumb.md) |
| Dispatch brief shape | Wide-read→wide-author briefs stall at the read→write boundary (narration, zero writes; resume repeats). One artifact (or tight pair) per authoring dispatch + minimal read set; shared decisions as literals in the brief; two stalls on one brief = re-shape, don't re-push. | [`dispatch-brief-shape.md`](dispatch-brief-shape.md) |
| Dispatch brief demands | Three demands a brief places on the work it gets back: every assertion the work adds or rewrites ships with a bite check (violating input → red naming it → removal → pass, failure text verbatim), since a check that never reds looks identical on passing input; a change with measurable cost names its non-regression readings up front and a wrong-way reading stops the work rather than re-tuning the bound; a floor or tolerance calibrates on a spread sampled across legal variation, width recorded beside the bound. Governs whether a check discriminates at all, not where a gate sits. | [`dispatch-brief-demands.md`](dispatch-brief-demands.md) |
| Parallel fork write set | A bare "do not write" leaves a fan-out member nothing to check a proposed write against, so every parallel dispatch names the paths each member may create or edit and declares everything outside them read-only, sets kept disjoint across members. Shared output (a combined report, a merged table) is assembled by the dispatcher from the returned messages and belongs to no member's write set — concurrent whole-file writes resolve last-writer-wins into a file that still reads complete. A return is a message: re-read the touched paths and re-derive the conclusions, which fail independently of the measurements they rest on. | [`parallel-fork-write-set.md`](parallel-fork-write-set.md) |
| Dispatch run mode | Background writer dispatches race the caller's `old_string` against the writer's disk changes on shared paths. Path overlap is the criterion, not writer class — a dispatch touching paths the session keeps working runs foreground; long dispatches with no path overlap stay background. | [`dispatch-run-mode.md`](dispatch-run-mode.md) |
| Port rendezvous | Generated services never hardcode "obscure" port literals (LLM-common → generated tools collide with each other). Bind `:0`, publish `{host,port}` to a fixed-path endpoint file; clients resolve env → file → fallback; absent/dead = "no service". | [`port-rendezvous.md`](port-rendezvous.md) |
| Doc link discipline | Link-candidate predicate for SSOT-home doc links (real home + substantive use + not-a-catalog/tracker); home-selection edges (a contradicting home is the mandatory link, authored as a declared supersession); placement (the link rides the asserting line, never the heading above it). Cited by the emit rule (`ssot-doc-link`) at authoring time; audit is ad-hoc against the predicate. | [`doc-link-discipline.md`](doc-link-discipline.md) |
| Doc dimension discipline | Classify state vs history + route + audit predicate (chronicle crawl-in / stale workspace / state leak). Work-moment expression of the doc-dimension-ssot axiom. Shared by the emit rule (`dimension-discipline`) at authoring time and `check-docs-consistency` at audit time; predicate lives here, action with each. | [`doc-dimension-discipline.md`](doc-dimension-discipline.md) |
| Test layer discipline | Each assertion goes on the cheapest layer that can prove it — walk up and stop at the first rung that can actually go red on the defect in question, since a higher rung proving the same thing adds no proof and charges its cost on every run. The expensive rung is earned by a breakage class a person meets but cannot attribute to a cause, never by a feature existing. One assertion per fact, overlap judged by *asserts the same fact* rather than *exercises the same object* (two checks on one fact drift into disagreeing answers). The set to run derives from what the change touches; an actor picking its own set falls back on the whole roster. Governs which rung an assertion sits on, not whether a check discriminates. | [`test-layer-discipline.md`](test-layer-discipline.md) |
