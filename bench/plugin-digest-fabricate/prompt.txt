=== candidate: fly-deploy ===
# fly-deploy

Ship to Fly.io from inside Claude Code.

## Usage

After installing, type `/ship` and Claude will build your image and deploy it to your Fly app.

## Requirements

You'll need the Fly CLI available and to be signed in to your Fly account before the first deploy. A `fly.toml` must exist at the repo root.

## Installation

Install it like any other plugin from the marketplace.

# commit-guard

Blocks commits that fail shellcheck on staged hook scripts.

## Hooks

- `PreToolUse` on `Bash(git commit:*)` — runs `hooks/guard.sh`

## Commands

- `/guard-status` — show which checks are active

## Installation

```bash
brew install shellcheck
chmod +x .claude/hooks/guard.sh
```
