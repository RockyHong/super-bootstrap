# Terminology

**Batch**: One scaled copy of a recipe, fixed to a target serving count and one unit system.
_Avoid_: run, scaled recipe

**Pantry**: The user's declared stock of ingredients with quantities, which every Batch draws against.
_Avoid_: inventory, stock list

**Shortfall**: The quantity of one ingredient a Batch needs beyond what the Pantry holds.
_Avoid_: deficit, missing item
