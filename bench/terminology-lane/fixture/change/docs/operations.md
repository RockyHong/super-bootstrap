# Operations

How an operator runs the brindle cabinet during a shift.

## Loading

Slide the trays in from the top shelf down and close the door. The panel shows the
recipe name and the target humidity before it starts.

## Pausing

Press Pause when the oven line backs up. The cabinet enters Hold: the cycle timer
stops while temperature and humidity stay at their set points, so dough waits without
over-rising. Press Resume on the panel to leave Hold and continue the timer.

Each rise run writes its humidity curve to the panel's log, one file per batch.

## Unloading

Open the door only after the panel chimes. Pull the trays from the bottom shelf up so
condensation does not drip onto finished dough.
