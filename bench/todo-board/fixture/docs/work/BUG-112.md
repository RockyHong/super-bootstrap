# BUG-112 — digest email sends twice when the scheduler restarts mid-batch

**Logged:** 2026-08-13 · **Source:** user report
**Problem:** A scheduler restart during a digest batch re-sends every message already delivered in that batch.
**Area:** src/notify/email.ts

## Amendment — 2026-08-14 · user report

A second report narrows it: only batches past the 50-message chunk size duplicate; smaller batches restart cleanly.
