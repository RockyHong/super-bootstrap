# BUG-110 — CSV export drops the header row on empty result sets

**Logged:** 2026-08-13 · **Source:** user report
**Problem:** Exporting a query with zero rows writes an empty file instead of a header-only CSV.
**Area:** src/reporting/csv.ts

## Verdict — surface · 2026-08-13

Two defensible outputs for an empty result set: header-only CSV, or no file at all plus a warning. Both are one-line changes; the fork is product taste, so it goes back to the user.

## Design — 2026-08-14

Header-only CSV. The export always writes a file; an empty result set yields the header line and nothing else (src/reporting/csv.ts).

Approved — 2026-08-14.
